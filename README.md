- **프로젝트 개요**
    - Unreal Engine 5와 Gameplay Ability System(GAS)을 기반으로 거점 건설 / 생산 / 채집 시스템을 구현한 팰월드 모작 프로젝트입니다.
    - 원작 리소스를 사용하되, 건설과 생산 시스템은 데디케이티드 서버 환경에 맞춰 직접 설계했습니다.
    - 건설 / 제작 / 기술 해금 / 자원 채집과 이를 다루는 UI를 담당했습니다.
    

---

- **개발 목표**
    - 소켓 스냅과 지지대 기반 연쇄 붕괴를 갖춘 건설 시스템 구현
    - 플레이어와 팰이 같은 작업 구조로 건설 / 생산 / 채집을 함께 진행하는 구조 구현
    - DataTable과 GameplayTag로 건축물 / 레시피 / 기술을 데이터만 추가해 확장하는 구조 구현
    - 태그 기반 UI 구조로 화면 전환과 입력을 일관되게 관리
    - 데디케이티드 서버 환경에서 건설 / 작업 진행 상태를 서버 기준으로 동기화
    

---

- **구현 목록**

| **구분** | **내용** |
| --- | --- |
| 건설 | 건축창(기능별 탭 / 해금 연동) <br> 미리보기 배치(시점에 따른 거리 조절) <br> 유효성 검사(표면 / 겹침 / 경사 / 지지대 / 거점) <br> 자동 / 수동 스냅 <br> 건설 진행도 / 건설 취소 및 재료 반환 <br> 해체 모드 <br> 지지대 기반 연쇄 붕괴 <br> Chaos Geometry Collection 파괴 연출 |
| 생산 | 레시피 선택 시설 / 생산품 고정 시설 <br> 제작창(제작 가능 순 정렬, 개수 입력) <br> 거점 상자 재료 공유 <br> 농장 작물 성장 단계 |
| 작업 | 플레이어 / 팰 공용 작업 어빌리티 (팀원이 구현한 팰 AI에 제공) <br> 팰 작업자 배정(작업 적성 / 최대 작업자 수) |
| 기술 트리 | 레벨 / 기술 포인트 기반 해금 <br> 건축물 / 레시피 해금 연동 |
| 자원 | 도구별 피해량 <br> 피해 누적 드롭 / 확률 드롭 테이블 <br> 고갈 및 리스폰 |
| 상호작용 | 겹침 + 시선 방향 기반 대상 탐지 <br> 상태별 키(누르기 / 길게 누르기) <br> 월드 UI 프롬프트 |
| 생존 / 장비 | 포만감 감소 / 굶주림 <br> 음식 섭취(직접 / 먹이 주머니 자동) <br> 무게 초과 시 이동 속도 감소 <br> 장비 스탯 반영 / 갑옷 메쉬 교체 / 헬멧 부착 <br> 방패 실드 및 재생 |
| UI | 태그 기반 화면 스택 매니저 <br> ViewModel 기반 데이터 바인딩 (팀 공용 구조 위에 기술 트리 / 건축창 ViewModel 구현) <br> 탭 / 재사용 버튼 / 툴팁 <br> HUD(실드 / 포만감 / 무게 / 경고) <br> 피해량 월드 UI <br> 타이틀 / 서버 접속
페이드 / 로딩 화면(팁 문구) <br> 사운드 옵션(로컬 저장) / ESC 메뉴 |
| 데이터 | AssetManager + GameplayTag 기반 DataTable 접근 |
| 연출 | 나이아가라 이펙트(팰 포획 / 투척 / 피격 / 채집 작업) |
| 맵 | 월드맵 제작 및 오브젝트 배치 |
